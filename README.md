## 🚀 How to Host on GitHub Pages (Step-by-Step)

### Step 1: Initialize Git in this directory
Open PowerShell or Terminal in this folder (`c:\Users\Faizal\Desktop\VK roofing website`) and run:
```bash
git init
git add .
git commit -m "Initial commit of VK Roofings static website"
```

### Step 2: Create a Repository on GitHub
1. Log into your account on [GitHub.com](https://github.com).
2. Click **New Repository**.
3. Name it `vk-roofing-website` (or `<your-username>.github.io` if you want it on the root domain).
4. Keep it **Public** and do not add a README or .gitignore (they are already included).
5. Click **Create repository**.

### Step 3: Push your code to GitHub
Run the commands shown on GitHub:
```bash
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/vk-roofing-website.git
git push -u origin main
```

### Step 4: Turn on GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** (top tab) → **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` and `/ (root)`.
4. Click **Save**.
5. Within 1–2 minutes, your website will be live at:
   `https://<YOUR-USERNAME>.github.io/vk-roofing-website/`

## 🌐 Custom Domain (Optional)
If you purchase a custom domain (e.g. `vkroofings.com`):
1. In GitHub Repository → **Settings** → **Pages** → **Custom domain**, enter your domain.
2. In your domain registrar (GoDaddy, Namecheap, Cloudflare, etc.), add CNAME record pointing to `<YOUR-USERNAME>.github.io`.
